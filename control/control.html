Room & Director

Slots bind guests by their vdo.ninja label; the hidden director iframe re-resolves label → current streamID every 2.5 s, so a guest who rejoins is re-followed automatically. Keep exactly one director page open (this page or director-min.html).
This page is not on a secure origin (crypto.subtle is unavailable) — the &hash= invite mode can't be computed here, and the director is NOT started: vdo.ninja would not accept it, and slots would never resolve. Open this page via http://127.0.0.1:<port>/ (not a LAN name or file://), or use plaintext/none password mode.

The bridge sidecar joins the current voice channel muted-but-listening and feeds the overlays. Its bot token is file-only: sidecar/discord-tokens.json (never configured from this page — everything on this bus is visible to every subscribed client). Start it with start-discord-bridge.bat or the optional "Discord Bridge Start" action.
Settings ride the discord:voice:update payload — the roster overlay re-styles live (URL params on the overlay override them; docs/THEMING.md).
